Как бесплатно опубликовать сайт на GitHub Pages за 2 минуты

1

Скачайте архив вашего сайта

Нажмите синюю кнопку «Скачать ZIP-архив» вверху страницы и распакуйте архив на компьютере.

2

Создайте репозиторий на GitHub

Перейдите на github.com/new, введите название репозитория (например, portfolio) и выберите Public.

3

Загрузите файлы index.html, style.css, script.js

Перетащите распакованные файлы в репозиторий на GitHub и нажмите Commit changes.

4

Включите GitHub Pages

В репозитории откройте Settings ➔ Pages ➔ в разделе Branch выберите main / root и нажмите Save.

🎉 Через 30 секунд ваш сайт будет доступен по ссылке:
https://ваш-логин.github.io/portfolio/
